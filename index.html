What it does

Run Windows commands

Console programs run against a real Windows kernel, not an emulation layer. The exit code you get back is the program's own.

winquick run -- cmd /c ver

Build and test

Your project appears inside Windows as the working directory. Build it, run its tests, and copy the output you asked for back out.

winquick run -w . -- dotnet test

Desktop applications

With the desktop capability, WPF and WinForms applications run in a real Windows desktop and can be driven through Microsoft UI Automation. Nothing appears on your screen.

winquick ui-test MyApp.csproj --script smoke.uitest

WinQuick is also an MCP server, so a coding agent can use the same commands: claude mcp add winquick -- winquick mcp

See it running

Every run

  • Starts from the same clean image and is discarded afterwards.
  • Your project is copied in, never copied back. Artifacts come out only when you ask for them.
  • The guest has no network adapter.
  • No daemon, no account, no telemetry.
