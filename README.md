# WinQuick landing page

Static landing page for [WinQuick](https://github.com/carlbomsdata/winquick) — **Instant disposable Windows environments.**

## Local preview

No build step or dependencies are required. Open `index.html` directly, or serve the repository with any static HTTP server.

For example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Hosting

The site is intentionally plain HTML, CSS and JavaScript and is suitable for GitHub Pages or any static host.
